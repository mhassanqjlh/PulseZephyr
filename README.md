# PulseZephyr

PulseZephyr is a Cloud-enabled platform for Real-time data processing, utilizing Serverless architecture with Auto-scaling Agents.

The key benefits of using PulseZephyr include:

- PulseZephyr is a Cloud-enabled platform
- for Real-time data processing, utilizing
- Serverless architecture with Auto-scaling Agents

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PulseZephyr.git`
2. `cd PulseZephyr`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
